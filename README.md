# Team Task Manager

A Django-based Team Task Management System with REST API support.

## Features
- User Login Authentication
- Admin and Member Roles
- Create and Assign Tasks
- Task Status Tracking
- Dashboard Statistics
- Django REST Framework APIs
- Project Management

## Technologies Used
- Python
- Django
- Django REST Framework
- HTML
- Bootstrap
- SQLite

## API Endpoints
- /api/projects/
- /api/tasks/

## Admin Access
Admin can:
- Create users
- Create projects
- Assign tasks
- Manage all tasks

Members can:
- View assigned tasks
- Update task status

## Run Project

```bash
python manage.py runserver
